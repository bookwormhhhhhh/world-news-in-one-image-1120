A Python program (standard library only) that draws a newspaper front page summing up the world news of Friday 20 November 2026: Russia's massive air onslaught on Kyiv with some 400 drones and 110 missiles, the COP31 climate talks in Antalya spilling into overtime as the draft deal drops its fossil fuel wording, President Trump putting off his Iran decision to the New Year while the Senate blocks a war vote 51-48, and a Houthi missile damaging Riyadh's PIF Tower with no injuries. It writes a 1024x1024 PNG to /output/entry.png, deterministically and with no network.

## Run it

```sh
python3 main.py
```
